# Giga Mines

A premium corporate website concept for Giga Mines, the critical-minerals and rare-earth refining vertical of MiniMines Cleantech Solutions Pvt Ltd.

## Run locally

```bash
pnpm install
pnpm dev
```

Open `http://localhost:3000`.

## Production

```bash
pnpm build
pnpm start
```

Deploy through the Vercel Publish flow or connect the project to GitHub.

## Implementation notes

- Built with Next.js App Router, TypeScript, Tailwind CSS, and lightweight React state.
- The facility plan, element list, impact figures, target markets, news items, contact details, and company claims are intentionally marked illustrative or to be confirmed.
- The enquiry form validates in the browser only. It does not send or persist data until a production endpoint is connected.
- Hero imagery is sourced from Unsplash and should be replaced with approved Giga Mines photography before launch.
- No environment variables are currently required.
